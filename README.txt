КРИСТАЛЬНЫЕ СТРАЖИ — Пинг v1.0.2
====================================
Это версия на основе фикса драфта v1.0.1. Исправление драфта сохранено.

НОВОЕ:
- В верхней панели отображается «Пинг: N мс» с цветной точкой.
- Пинг измеряется настоящим WebSocket запросом ping/pong до вашего сервера.
- Проверка каждые 3 секунды, без нагрузки на игровой процесс.
- Зелёный: менее 100 мс; жёлтый: от 100 до 199 мс; красный: 200+ мс.
- При потере связи вместо старого числа показывается «Пинг: —».
- Если ответа нет больше 9 секунд, показывается «Пинг: >9 с».
- Видно также в меню и во время драфта.

Важно: это задержка между вашим браузером и игровым сервером, а не FPS
и не полный отклик игры/время прохождения команды до другого игрока.

КАК ОБНОВИТЬ РАЗВЁРНУТУЮ ИГРУ:
1. На GitHub откройте ваш репозиторий Ni.
2. Загрузите ОБНОВЛЁННЫЙ index.html в корень репозитория (вместо старого).
   Можно также загрузить package.json, чтобы версия стала 1.0.2.
   server.js не менялся и может оставаться как есть.
3. Нажмите Commit changes.
4. Дождитесь успешного обновления на Render (Live).
5. Вы оба обновите страницу Ctrl+F5 и создайте новую комнату.

Если GitHub не предлагает замену, откройте существующий index.html,
нажмите значок карандаша/изменения и используйте загрузку файла через
Add file -> Upload files в корне репозитория.

В архиве есть сервер для самостоятельного размещения:
node server.js (Node.js 18+; зависимости не требуются).
